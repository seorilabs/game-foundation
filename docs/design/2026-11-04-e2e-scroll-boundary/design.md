# E2E 스크롤 끝 경계 수정

betta-raising CQ-1의 390×844, 한국어, 글자 130% 환경에서 스크롤을 끝까지 이동한 뒤에도 취소 버튼 입력 준비가 실패했다. 글로벌 Rect2의 좌표를 별도 float로 더하면 실제로 같은 끝 경계에 0.000030517578125픽셀 차이가 남는다. 공통 도구가 이 차이를 가림으로 판정해 불가능한 추가 스크롤을 시도했다.

화면보다 작은 컨트롤의 시작과 끝 경계에 Godot의 근사 동일 비교를 적용한다. 실제 1픽셀 가림과 화면보다 큰 컨트롤의 중심 입력 경계는 유지한다. 제품 화면과 저장에는 변경이 없다. 소비 앱의 고정 파일을 직접 수정하지 않고 이 원본의 검수한 커밋을 묶음으로 설치한다.

사용자가 2026-11-03T15:08:12Z에 betta-raising의 추가 진단, 필요한 공통 도구 수정과 독립 4회차 전체 검수를 승인했다. 원 승인 기록은 betta-raising의 docs/design/2026-11-03-commercial-quality/approval-round4.md, 커밋 87700d6에 있다. 이 저장소의 도구 수정은 L1 dev로 재현 검사와 전체 npm test, 320×568 렌더 여정을 실행한다. 소비 앱의 L3 dev 전체 검수는 독립 검수자가 별도로 실행한다. release는 null이며 기기와 마켓 배포는 포함하지 않는다.

인수조건은 실제 스크롤 후 버튼 pressed 1회, 1픽셀 가림과 큰 컨트롤 경계 유지, 렌더링 재현의 RED→GREEN, npm test와 작은 화면 렌더 및 묶음 해시 검증이다. build/scroll-boundary/red-exact와 green-exact에 수정 전 exit 1과 수정 후 exit 0을 기록했다. 이보다 앞선 직접 소수 위치의 ScrollContainer 시험은 스크롤 페이지 반올림으로 다른 1픽셀 문제를 만든 탐색 실행이며 회귀 증거로 사용하지 않는다.
